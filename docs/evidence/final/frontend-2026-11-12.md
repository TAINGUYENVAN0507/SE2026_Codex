## Lệnh

```powershell
git clone --branch main --single-branch https://github.com/TAINGUYENVAN0507/SE2026_Codex.git <thu-muc-moi>
cd <thu-muc-moi>/frontend
npm ci
npm run lint
npm run format:check
npm run typecheck
npm run test:coverage
npm run build
npx playwright install chromium
# Tạo PostgreSQL E2E, đặt E2E_DATABASE_URL, SEED_DEMO_PASSWORD,
# DEBUG=false, FAKE_SCENARIO=slow theo frontend/README.md.
# UV và FFPROBE_BIN trỏ tới executable nếu công cụ không ở PATH.
npm run e2e
```

Ở lượt đầu coverage lỗi nên chuỗi lệnh dừng trước build/E2E. Sau commit sửa, checkout sạch commit nêu trên rồi chạy lại lint → format → typecheck → coverage → build → E2E. Source trong JSON là commit thực sự đã chạy, không ghi là main nguyên bản đã xanh.
