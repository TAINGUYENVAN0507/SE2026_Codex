## 3. Khởi động PostgreSQL 16 và Chạy Migration theo README

Theo hướng dẫn tại `README.md` và `backend/README.md`:

```bash
# 1. Sao chép biến môi trường
cp .env.example .env
cp .env.example backend/.env

# 2. Khởi động PostgreSQL 16 container qua Docker Compose
docker compose up -d db

# 3. Kiểm tra trạng thái container
docker compose ps
# meeting_assistant_db | postgres:16 | Up (healthy) | 0.0.0.0:5432->5432/tcp

# 4. Thực thi migration database lên phiên bản mới nhất
cd backend
uv run alembic upgrade head
```

## 5. Kiểm tra Khởi chạy Dịch vụ API Server và Background Worker

Thực hiện kiểm chứng chạy dịch vụ cục bộ theo đúng hướng dẫn trong `backend/README.md`:

1. **API Server:**
   ```bash
   uv run uvicorn app.main:app --port 8000
   ```
   - Kiểm tra endpoint kiểm tra sức khỏe: `curl http://localhost:8000/ready` → `{"status":"ready","database":"connected"}`.
   - Kiểm tra tài liệu Swagger: `http://localhost:8000/docs` trả về mã 200 OK.

2. **Background Worker:**
   ```bash
   PIPELINE_BACKEND=fake uv run python -m app.worker.runner
   ```
   - Worker khởi chạy ở chế độ pipeline giả lập, kết nối thành công tới database PostgreSQL, lắng nghe hàng đợi `jobs` và chạy heartbeat bình thường.
