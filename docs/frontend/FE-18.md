# FE-18 — Dẫn chứng cho biên bản

## Export

Module thuần `backend/app/services/export/` giữ nguyên chữ ký hàm. JSON tăng
minor lên 1.1 theo `structure/contracts.md`: action có `evidence_segment_ids`
mặc định `[]` và `needs_review` mặc định `false`. DTO cũ vẫn được chấp nhận.
Với `ai_original`, hai field lấy từ dữ liệu AI gốc, không lấy bản đã sửa.

TXT và Markdown in dẫn chứng sau từng ý chính, quyết định và công việc bằng
mốc `hh:mm:ss` cùng tên người nói của biến thể được chọn. Thiếu hoặc mất id
thì hiện “Chưa có bằng chứng, cần kiểm tra”; tham chiếu hợp lệ khác vẫn được
giữ. Không sinh mốc giả. Chữ người dùng được escape trong Markdown.

Schema được sinh bằng `python -m app.services.export`; không sửa JSON bằng tay.
Các file golden cập nhật cả hai biến thể; test gọi serializer 3 lần, so byte
và kiểm tra đầu vào không bị sửa. Lint/format backend và **21 test export đạt**.

## Phối hợp

B review schema 1.1 và truyền đủ hai field từ database qua DTO trong service
`meeting_export.py`. Router DB là phạm vi B. E2E file tải xuống khớp UI nằm
ở đợt 2 theo roadmap; không dùng mock để tuyên bố tích hợp DB đã hoàn tất.
