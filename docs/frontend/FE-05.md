# FE-05 — Upload và chống request trùng

Owner: member A · cập nhật: 20/10/2026.

## Giới hạn file

Frontend validate file theo `UploadConfig` (`max_upload_mb` và
`allowed_extensions`). Bản demo hiện dùng cấu hình mặc định 200 MB và danh sách
đuôi audio được hỗ trợ; đây là giá trị tạm cho đến khi backend cung cấp
`GET /api/v1/config`. Kích thước ghi âm, phần mô tả định dạng và thông báo lỗi
đều lấy từ cùng cấu hình.

Kiểm thử: `src/features/audio/validation.test.ts` bao phủ file rỗng, quá dung
lượng, đuôi không hỗ trợ, đuôi viết hoa và file hợp lệ. API config thật và
Idempotency-Key sẽ được gửi khi API upload được kết nối.

## Khóa chống request trùng

`useIdempotencyKey(file)` sinh UUID cho file đang chọn. Giữ nguyên cùng object
`File` thì giữ khóa qua rerender/retry; chọn file khác sẽ sinh khóa mới; bỏ
chọn file trả về `null`. Hook sẵn sàng để gắn header `Idempotency-Key` khi kết
nối API upload.

Kiểm thử `useIdempotencyKey.test.ts` xác nhận cả ba hành vi.
