# FE-09 — Transcript từ API

Owner: member A · cập nhật: 22/10/2026.

Trang chi tiết lấy `GET /api/v1/meetings/{id}` và
`GET /api/v1/meetings/{id}/transcript` qua React Query. Khi transcript còn
`pending`, giao diện hiện skeleton và tự kiểm tra lại. Khi `ready`, các đoạn
liền nhau của cùng người nói được nhóm trực quan; thời gian theo `hh:mm:ss`.
Đoạn có `speaker_id: null` hiện “Chưa xác định” màu xám. Các cờ
`low_confidence` và `overlap` có badge riêng.

MSW dùng `transcript_ready.json` và `transcript_pending.json`.
`TranscriptApi.test.tsx` kiểm tra dữ liệu fixture, nhóm đoạn, định dạng thời
gian, pending và đường gọi API từ trang chi tiết.
