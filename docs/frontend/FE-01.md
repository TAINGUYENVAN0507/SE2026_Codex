## Chạy từ bản clone sạch

Yêu cầu Node.js 24 (ghi trong `frontend/.nvmrc`) và npm.

```bash
cd frontend
npm ci
npm run dev
```

Mở URL Vite in trong terminal, thường là `http://localhost:5173`.
PowerShell chặn `npm.ps1` thì dùng `npm.cmd`.
Windows báo EPERM khi `npm ci`: dừng dev server frontend rồi thử lại; Vite có thể
giữ native binding trong `node_modules`.

## Kiểm tra giống CI

Chạy trong `frontend/`, lần lượt:

```bash
npm run lint
npm run format:check
npm run typecheck
npm test
npm run build
```
