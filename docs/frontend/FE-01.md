Code và kiểm tra local được chuẩn bị để bàn giao. Chưa commit/push theo yêu cầu

## Đối chiếu tiêu chí

Các đường dẫn bên dưới thuộc `frontend/`, trừ workflow.

| Tiêu chí | Bằng chứng |
| --- | --- |
| Vite + React + TS strict | `package.json`, `vite.config.ts`, `tsconfig.app.json` (`strict: true`) |
| React StrictMode | `src/main.tsx` |
| ESLint, Oxlint và Prettier | `eslint.config.js`, `.oxlintrc.json`, `.prettierrc.json` |
| Layout | `src/components/AppShell.tsx`, `Topbar.tsx` |

| Provider | `src/app/AppProviders.tsx`: BrowserRouter và QueryClient ổn định qua rerender |
| Smoke test | `src/app/scaffold.test.tsx`: 6 route trong StrictMode, redirect gốc, provider |
| CI | `.github/workflows/frontend.yml`: cài lockfile, lint, format, typecheck, test, build |

## Chạy từ bản clone sạch

Yêu cầu Node.js 24 (ghi trong `frontend/.nvmrc`) và npm.

```bash
cd frontend
npm ci
npm run dev
```

Mở URL Vite in trong terminal, thường là `http://localhost:5173`.
PowerShell chặn `npm.ps1` thì dùng `npm.cmd`.
Windows báo EPERM khi `npm ci`: dừng dev server frontend rồi thử lại; Vite có thể
giữ native binding trong `node_modules`.

## Kiểm tra giống CI

Chạy trong `frontend/`, lần lượt:

```bash
npm run lint
npm run format:check
npm run typecheck
npm test
npm run build
```

Server được mở lại trên cổng 5173 sau kiểm tra.

tương ứng, hoặc chạy thủ công. Không tự push chỉ để kích hoạt CI.
