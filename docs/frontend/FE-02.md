# FE-02 — REST API client và API errors

Owner: member A · cập nhật: 21/10/2026.

## Đã làm

`src/api/errors.ts` đọc error envelope `error.code`, `error.message`,
`error.details` và `error.request_id` thành `ApiError`. Các mã thường gặp có
thông báo tiếng Việt; mã chưa biết giữ nội dung từ server. Body sai cấu trúc
hoặc không phải JSON dùng `UNKNOWN_ERROR`; lỗi kết nối được chuẩn hóa qua
`toNetworkError()` thành `NETWORK_ERROR`.

`npm run gen:api` sinh `src/api/schema.d.ts` từ `contracts/openapi.json`. CI sinh
lại và kiểm drift khi contract đổi. `src/api/client.ts` dùng `openapi-fetch` với
`credentials: 'include'`, cung cấp `getMeeting(id)` và `getJob(id)` theo type sinh
từ contract. Lỗi HTTP và lỗi mạng đều chuyển thành `ApiError`.

`src/mocks/handlers.ts` đọc trực tiếp hai fixture REST của backend. Test client
dùng MSW, không gọi mạng thật. Chạy `VITE_API_MOCK=1 npm run dev` để bật mock
trong browser; nếu không bật, request sẽ tới API thật.

Giao diện demo hiện tại chưa đổi sang dữ liệu API, vì contract v0 mới cung cấp
endpoint chi tiết meeting và job. Kiểm thử có 200, 404 và lỗi mạng. Chạy đủ
lint, format, typecheck, test và build tại `frontend/`.
