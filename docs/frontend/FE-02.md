# FE-02 — API client, proxy và mock auth

Owner: member A · cập nhật 24/10/2026.

Client dùng type sinh từ `contracts/openapi.json`, gửi cookie bằng
`credentials: 'include'` và chuẩn hóa lỗi HTTP/mạng thành `ApiError`.
Sinh lại type bằng `npm run gen:api`, không sửa tay file sinh.

Vite proxy giữ nguyên `/api`, mặc định chuyển tới `http://localhost:8000`.
Đổi backend bằng `VITE_API_PROXY_TARGET`. Chạy `$env:VITE_API_MOCK = '0'`
trước `npm run dev` trên PowerShell để tắt MSW và dùng API thật cùng origin.
Backend cần PostgreSQL, migration và tài khoản đã tạo/seed theo README backend.

Dev mặc định bật MSW, dùng fixture chung trong `contracts/fixtures/api/`.
Mock auth có login/me/logout; tài khoản giả được ghi trong README frontend.
Mật khẩu sai trả 401 `INVALID_CREDENTIALS`; logout xóa phiên trong bộ nhớ mock.
MSW không mô phỏng độ bảo mật của cookie HttpOnly trên server thật.

`proxyConfig.test.ts` kiểm tra target mặc định và tùy chỉnh. `auth.test.ts`
kiểm tra 401, login/me theo fixture và logout. Các test API khác kiểm tra
contract, lỗi mạng và error envelope; kiểm tra tích hợp thật được ghi ở FE-03.
