# FE-16 — Lỗi giao diện và mất kết nối

Owner: member A · cập nhật 24/10/2026.

`RouteErrorBoundary` bọc Outlet, thay component lỗi bằng thông báo chung và nút
Tải lại. Chuyển sang route khác tạo boundary mới. Không đưa error message,
stack trace hoặc nội dung transcript vào fallback.

`ConnectivityNotice` đọc `navigator.onLine`, theo dõi online/offline và hiện
banner khi mất mạng. API client và upload XHR báo lỗi mạng qua toast chung;
toast tự ẩn sau 6 giây hoặc đóng bằng nút.

Route lạ dùng trang 404. Chi tiết cuộc họp dùng cùng trang 404 khi ID không hợp
lệ hoặc API trả `MEETING_NOT_FOUND`/HTTP 404. Lỗi không có mã được nhận biết
chỉ hiển thị thông báo chung, không chuyển nguyên message server ra giao diện.

Test kiểm tra component ném lỗi, fallback không lộ canary, chuyển route sau lỗi,
online/offline, toast lỗi mạng, route lạ và cuộc họp không tồn tại.

QA API thật phát hiện mốc player demo 255 giây vượt quá bản ghi ngắn, khiến
vạch waveform kéo trang tràn ngang. Vị trí ban đầu và tỷ lệ tiến độ đã được
giới hạn theo duration. Test hồi quy trong `PlayerSync.test.tsx` đã fail với
progress 1839.8% trước bản sửa và kiểm tra giới hạn 100% sau bản sửa.

Kiểm tra cuối: lint, format, TypeScript, 136 test và production build đạt.
Browser QA thật xác nhận offline/online, 401 và route 404; ở viewport 375px,
`documentElement.scrollWidth` bằng 375px sau bản sửa player.
