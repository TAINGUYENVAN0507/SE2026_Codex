# AI-17 · Ranh giới adapter của bên thứ ba

Mọi thư viện hoặc dịch vụ ngoài được bọc trong một adapter. Stage và backend chỉ biết interface.
Ranh giới không còn nằm ở tài liệu: hai test duyệt AST (kể cả import trong hàm) sẽ đỏ nếu bị phá.

## Bảng dịch vụ

| Bên thứ ba | Dùng để | Interface | Adapter thật (chỗ duy nhất được import) | Bản fake | Dữ liệu rời máy |
|---|---|---|---|---|---|
| `faster-whisper` (CTranslate2) | ASR, VAD | `AsrEngine`, `VadEngine` (`engines/base.py`) | `engines/whisper.py` | `engines/fake.py` | Không. Chạy cục bộ. Tải trọng số model lần đầu |
| `pyannote.audio`, `torch` | Diarization | `DiarizeEngine` | `engines/pyannote.py` | `engines/fake.py` | Không. Chạy cục bộ. Tải trọng số model lần đầu |
| `huggingface_hub` | Tải và kiểm model | `models.py` | `models.py` | Không cần | Chỉ tên repo và token (không gửi audio) |
| Claude API (`anthropic`) | Tóm tắt | `LLMProvider` (`llm/base.py`) | `llm/anthropic.py` | `llm/fake.py` | **Text transcript** và ngày họp. Mặc định `LLM_PROVIDER=disabled`: không gửi gì (PRIV-16) |

## Phía backend

| Quy tắc | Lý do |
|---|---|
| Ngoài `app/worker/` không file nào import `meeting_pipeline` | API không phụ thuộc pipeline; lỗi pipeline không kéo API sập |
| `app/worker/` chỉ import `meeting_pipeline.runner`, `.schemas`, `.errors` | Worker gọi `run_job`, không biết stage hay engine |
| Backend không import SDK đã được pipeline bọc | Đổi nhà cung cấp chỉ đụng một file trong pipeline |

## Test bảo vệ

| Test | Bảo vệ |
|---|---|
| `pipeline/tests/unit/test_adapter_boundary.py` | Bảng SDK → file được phép. Có test âm: đoạn source vi phạm phải báo `file:dòng` |
| `backend/tests/unit/test_adapter_boundary.py` | Ba quy tắc ở trên |

Thêm SDK mới: khai báo ở `RULES` rồi mới import. Test `test_every_allowed_adapter_exists` báo lỗi nếu đổi tên adapter mà quên cập nhật `RULES`, tránh rule mất tác dụng trong im lặng.

## Vi phạm đã sửa

`models.py` import `faster_whisper.utils._MODELS` (API private của SDK) ngoài `engines/`. Hàm `asr_repo` chuyển sang `engines/whisper.py`; `models.py` chỉ gọi lại qua `WhisperConfig`.
